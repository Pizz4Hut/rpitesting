Raspberry Pi Setup Instructions

Run this Python agent script on your Raspberry Pi (Raspberry Pi 3, 4, 5, or Zero 2W). It automatically gathers CPU temperature, load, RAM, disk, IP, and pushes telemetry to your Netlify website!

Step 1: Install Python dependencies on Pi

sudo apt update && sudo apt install -y python3-pip
pip3 install requests psutil

Step 2: Run the Pi Agent Script

Copy the script in pi-client/pi_agent.py onto your Pi, or test immediately with this one-liner command:

python3 pi_agent.py --url https://YOUR-NETLIFY-SITE.netlify.app/api/telemetry --interval 10

Step 3: Run as Auto-Starting Systemd Service (Optional)

A ready-to-use systemd configuration file is included in pi-client/pi-agent.service for 24/7 background monitoring on boot.

REST API Reference

POST /api/telemetry

Receive sensor & status data from Raspberry Pi

curl -X POST "https://YOUR-SITE.netlify.app/api/telemetry" \
  -H "Content-Type: application/json" \
  -d '{
    "deviceId": "raspberrypi-living-room",
    "deviceName": "Living Room Pi 4",
    "system": {
      "cpuTemp": 48.5,
      "cpuUsage": 14.2,
      "ramUsage": 32.5,
      "diskUsage": 45.1,
      "uptimeSeconds": 86400,
      "ipAddress": "192.168.1.105"
    },
    "sensors": {
      "ambientTemp": 23.4,
      "humidity": 55.2
    }
  }'
GET /api/devices

Fetch all registered devices and latest telemetry

DELETE /api/devices/:id

Remove a device from monitoring
